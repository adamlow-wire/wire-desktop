## Security and review

Substantive review covers the coordinator, broker and adapter, fixed IPC contracts, local content serving/CSP, PiP ownership, native main-process composition, existing account/menu/notification routes, fixtures and CI. No identified production defect or security-invariant exception remains in this source review. This is not independent release security review.

Remote content stays sandboxed and context-isolated, without Node, raw Electron or generic IPC. The broker has its own session, no ambient account credentials, fixed assets, literal source labels and denied remote navigation/popups/downloads. Native source authority remains in main and the trusted local broker. The main-world compatibility adapter can neither select native sources nor grant capture authority.

The approved relay is video-only, at most 3840×2160 and five frames per second, with one cached and one transferred RGBA image. Main and receiver deadlines end stalled flows within ten seconds; source choice expires after sixty seconds. Pending consent requires foreground/current ownership; an already-approved call may continue in the background with a visible Stop window. Stale identity, owner loss, malformed data and native failures end capture. Electron remains 43.4.0; pinning and mandatory Chromium certificate validation are unchanged, with no invented MDM policy.

Sensitive checks include removing native source approval, frame bounds, literal source-label handling and parent-hide revocation. Each fails its intended target before restoration. The tooling baselines expose repeated registration addresses, safe HTTP-status loss, persisted-worker startup, native Quit-veto cleanup and exit before an inspector reply. The worker race is timing-dependent: one unpatched run passed, then one of three failed; three restored runs passed. No assertion/deadline/retry was weakened.
